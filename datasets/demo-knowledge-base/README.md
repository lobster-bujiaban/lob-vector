# 典型知识库对照集

用于 Stage 0 对比本地 Hash Embedding 与真实语义 Embedding。内容均为虚构的通用产品文档，不包含共享知识库或个人敏感数据。

数据集包含 10 份源文件，覆盖账号、发票、退款、设备、开放 API、缓存、租户权限、RAG、Agent 和可观测性。每份文件包含两个主题相近但答案边界明确的章节，用于制造合理干扰项。

对照时重点观察：

- 预期章节进入 TopK 的排名，而不是跨模型比较相似度绝对值。
- 两种模型 TopK 的重合数量与 Top 1 是否相同。
- 同义改写、口语表达和原文关键词不一致时，真实语义模型是否仍能命中。

推荐首题：“登录凭据想不起来，该怎样重新进入账号？”预期命中 `01-account-security.md` 的“忘记密码”。

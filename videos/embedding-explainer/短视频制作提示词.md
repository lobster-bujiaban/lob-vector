# 抖音科普短视频制作提示词

把下面的科普内容制作成抖音竖屏短视频，输出到项目的 `videos` 目录。

要求：

- 画面比例 9:16，分辨率 1080×1920。
- 时长控制在 50～60 秒。
- 风格采用深色科技感、动态图解，信息清晰易懂。
- 使用 Edge TTS 生成中文旁白。
- 音色使用 `zh-CN-XiaoyiNeural`。
- 根据旁白实际时长调整语速、镜头时间和字幕节奏，禁止截断旁白。
- 前 3 秒设置悬念、问题或反常识钩子，避免教科书式开场。
- 每 3～6 秒切换一次画面重点。
- 旁白口语化，减少长句和不必要的专业术语。
- 画面包含标题、关键字幕、动态图示、对比例子和最终结论。
- 不使用来源不明或存在版权风险的素材，优先程序化绘制。
- 结尾用一句话总结核心知识，并可留下下一期话题。
- 输出可以直接播放的 MP4。
- 同时保留旁白稿、画面配置和重新渲染脚本。
- 生成后检查视频分辨率、比例、时长、编码和音轨，并抽查开头、中段、结尾关键画面。

